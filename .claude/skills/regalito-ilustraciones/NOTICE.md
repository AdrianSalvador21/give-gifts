# Aviso

Esta skill es una adaptación de **Ian Xiaohei Illustrations**, creada por Ian y publicada bajo licencia MIT (ver `LICENSE`).

- Repositorio original: <https://github.com/helloianneo/ian-xiaohei-illustrations>
- Autor: <https://github.com/helloianneo>

Cambios respecto al original: traducida al español; el personaje «小黑» se sustituyó por la mascota propia «Regalito»; se cambió la paleta y se permiten rellenos planos de color; fondo transparente por defecto para assets web; la generación de imágenes usa la API de OpenAI mediante `scripts/generar.mjs` en lugar de la herramienta `image_gen` de Codex. No se incluyen las imágenes de ejemplo del original.
